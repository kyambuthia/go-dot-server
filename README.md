## GO-DOT-SERVER
a simple server to test godot games exported to the web locally

using this to learn how to self host a godot game (local during dev and in prod), networking in golang/web, multiplayer in godot and websockets - so this is a learning kind of project

the goal here is to write a program to self-host a godot export on the web using go - first locally and eventually in prod and learn how godot handles networking.

## Project Versions
godot - Version 4.2.1
Go - Version 1.2.3
